# 系统架构设计师个人知识库

面向 **2026 年下半年系统架构设计师** 的本地学习中枢。它将教材知识、XMind、章节播客、真题、案例、论文、模拟、机考、错题与周复盘组织为可执行的学习路径。

## 从这里开始

1. 打开 [学习导航](00-学习导航.md)，执行今天与本周任务。
2. 在 [知识点阅读器](01-知识点/章节/) 中按章节树或搜索定位 503 个教材知识点。
3. 在 [真题索引](02-真题索引/README.md) 选择年份和科目完成限时练习。
4. 进入 [案例与论文](03-案例与论文/README.md) 或 [模拟与机考](04-模拟与机考/README.md) 进行输出训练。
5. 用 [错题与复盘](05-错题与复盘/README.md) 记录错误，周日调整下一周计划。

### 章节播客

在本地学习网站的冲刺指挥台点击“打开节目库”，可按章节收听节目；知识点阅读器也会显示对应章节的“播放本章播客”入口。播放进度只保留在当前浏览器，只有主动点击“记录本章收听 / 复盘”并提交时才写入 Markdown 学习档案。当前覆盖第 2、3、5–20 章；第 1、4 章暂无节目。

也可以运行 `python3 本地学习服务.py` 后在本地浏览器使用学习网站。公开仓库的最小可运行入口与版权边界见[根目录 README](../README.md)。

## 资料边界

- 当前工作区的计划、模板、Markdown 源稿与 XMind 是本知识库的学习资产。
- 章节播客为本机音频资产，服务仅按受控章节清单播放，不复制到网站静态目录或公开仓库。
- 真题、范文、模拟卷等外部资料仅应保留在使用者自己的本机；公开仓库不复制、不嵌入、不发布其文件内容，也不提交本机路径台账。

### GitHub 来源分层

本知识库从公开 GitHub 仓库摄取资料时按许可分层处理：

| 层级 | 内容 | 存放位置 | 是否公开 |
|---|---|---|---|
| 来源索引 | 仓库名、URL、采集时间、访问状态 | `题库数据/来源索引/外部来源.json` | ✅ 公开 |
| 知识点派生数据 | 503 个知识点的摘要、结构化理解、正文分段 | `site/knowledge-data.js` | ✅ 公开 |
| 站点索引元数据 | 年份、科目、标题、状态（不含路径） | `site/data.js` | ✅ 公开 |
| 私有台账 | 本机绝对路径白名单 | `真题台账私有.json` | ❌ 已忽略 |
| 原始资料快照 | 12 个仓库完整归档约 599 MB | `2026下半年系统架构师备考资料/github提取/` | ❌ 已忽略 |
| 教材源稿 | 从清洗稿转换的 XMind 源稿 | `2026下半年系统架构师备考资料/xmind/源稿/` | ❌ 已忽略 |

公开仓库只保留「代码 + 自编题 + 不含正文的来源索引 + 知识点派生数据」；教材、大纲、真题正文与内部路径均留在本机。

访问任何外部资料前，请自行确认版本、出处、版权和自己的使用权限。特别注意：仓库标注 `MIT`/`Apache-2.0` 通常只覆盖其**自有代码**，不覆盖其收录的教材、真题与答案解析；`CC BY-SA 4.0` 覆盖原创解析但要求署名与相同方式共享。回忆版、机构解析、范文均不能替代官方大纲和教材。

## 考试事实

官方 2026 年工作安排的系统架构设计师开考窗口为 **10 月 24 日至 27 日**；个人机考日期和场次以准考证为准。考试设综合知识、案例分析、论文三科，均为计算机化考试。来源见 [备考资料的官方来源说明](../2026下半年系统架构师备考资料/00-使用说明与官方来源.md)。
