## 记录规则

1. 综合题：记录“错误原因 + 下次判断规则”，在 +3 / +10 / +28 天复习。
2. 案例：记录漏答的关键词、题干约束和错因（概念/审题/表达/时间）。
3. 论文：记录跑题、真实性、结构、技术准确性、关键词覆盖五项反馈。
4. 周日：只选两个最高频弱项安排到下周，避免把所有错题同时重做。
