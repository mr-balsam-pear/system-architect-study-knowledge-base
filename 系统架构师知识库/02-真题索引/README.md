# 真题索引

## 使用方式

1. 优先完成近 5 年可确认的真题；再按薄弱专题回溯旧题。
2. 综合知识限时完成后，用 [错题本模板](../学习计划/03-错题本模板.md) 记录错因。
3. 案例题先用 [案例答题模板](../学习计划/04-案例答题模板.md) 提取约束和每问关键词，再对照解析复盘。
4. 论文题只作为审题与主题训练，正文必须使用自己的真实项目素材，见 [论文素材库模板](../学习计划/05-论文项目素材库模板.md)。

## 资料台账

[真题台账.csv](真题台账.csv) 由本机 `真题台账私有.json`（不公开）生成，每行只含元数据和绝对路径，不含题目正文。该 CSV 已被 `.gitignore` 排除，**不会进入公开仓库**；公开站点只读取不含路径的 [site/data.js](../site/data.js)。

字段说明：

| 字段 | 含义 |
|---|---|
| `year` / `session` | 文件夹或文件名可识别的考试年份、批次 |
| `subject` | 综合知识、案例分析、论文、答案解析或综合包 |
| `material_type` | 真题、答案解析、回忆版 |
| `absolute_path` | 本机原文件路径；仅存在于私有台账与 CSV，不进入公开仓库 |
| `status` | 文件版本、来源与使用权需要你自行核验 |

### 本机资料来源

台账当前登记 **107 份 PDF**，覆盖 2009–2026 年，来自本机 `2026下半年系统架构师备考资料/github提取/`（同样被 `.gitignore` 排除）。主要来源为公开仓库 [xiaomabenten/system_architect](https://github.com/xiaomabenten/system_architect)（MIT 只覆盖其自有代码，真题正文著作权归原权利人）与 [i0Ek3/cs-ruankao](https://github.com/i0Ek3/cs-ruankao)。

完整仓库清单、固定 commit 与许可状态见：

- `github提取/本机台账.md`（完整清单，本机）
- `github提取/_来源清单/*.json`（逐仓库快照元数据，本机）
- [题库数据/来源索引/外部来源.json](../题库数据/来源索引/外部来源.json)（公开，只含名称、URL 与访问状态）

### 重新生成台账

```bash
python3 "2026下半年系统架构师备考资料/github提取/_工具/生成私有台账.py" --write
python3 "2026下半年系统架构师备考资料/github提取/_工具/清点来源.py" --write
```

## 训练顺序

近年真题 → 对照答案/解析 → 错题归因 → 同专题案例 → 一次限时模拟。不要只累计刷题数量。

本知识库未在公开仓库复制任何 PDF、题目正文、答案或解析；公开仓库只保留不含正文的来源索引。第三方资料的版本、出处与使用权限请自行核验。
