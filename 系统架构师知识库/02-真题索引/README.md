# 真题索引

## 使用方式

1. 优先完成近 5 年可确认的真题；再按薄弱专题回溯旧题。
2. 综合知识限时完成后，用 [错题本模板](../../2026下半年系统架构师备考资料/03-错题本模板.md) 记录错因。
3. 案例题先用 [案例答题模板](../../2026下半年系统架构师备考资料/04-案例答题模板.md) 提取约束和每问关键词，再对照解析复盘。
4. 论文题只作为审题与主题训练，正文必须使用自己的真实项目素材，见 [论文素材库模板](../../2026下半年系统架构师备考资料/05-论文项目素材库模板.md)。

## 资料台账

[真题台账.csv](真题台账.csv) 由外部本机项目的文件名生成。每行只含元数据和绝对路径，不含题目正文。

字段说明：

| 字段 | 含义 |
|---|---|
| `year` / `session` | 文件夹或文件名可识别的考试年份、批次 |
| `subject` | 综合知识、案例分析、论文、答案解析或综合包 |
| `material_type` | 真题、答案解析、回忆版 |
| `absolute_path` | 你本机外部项目中的原文件路径；复制后通过 Finder 或 PDF 阅读器打开 |
| `status` | 文件版本、来源与使用权需要你自行核验 |

## 训练顺序

近年真题 → 对照答案/解析 → 错题归因 → 同专题案例 → 一次限时模拟。不要只累计刷题数量。

外部资料路径来自 `system_architect-main`，本知识库未复制其 PDF、题目、解析或范文内容。
