# 案例与论文训练

## 案例分析

- 作答模板：[案例答题模板](../学习计划/04-案例答题模板.md)
- 每周至少 1 道，9 月起每周 2 道；先列题干事实，再逐问写“风险/问题 → 措施 → 代价/边界 → 验证”。
- 重点专题：质量属性与 ATAM、分层、云原生/SOA 治理、安全体系、可靠性与演化、大数据选型。

## 论文

- 项目素材：[论文项目素材库模板](../学习计划/05-论文项目素材库模板.md)
- 教材方法：[第 20 章源稿](../学习计划/05-论文项目素材库模板.md)
- 训练目标：6 个提纲、至少 5 篇完整限时论文、3 个可切换的真实项目。

## 外部索引的正确用法

外部项目中的论文真题、范文与技巧资料只可用于识别题目范围、审题方式和结构差异。不要照抄范文，不要虚构项目职责或量化指标；文件来源与使用权请自行核验。
