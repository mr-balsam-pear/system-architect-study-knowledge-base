# 互动题库数据

本目录保存系统架构设计师备考用的结构化题库。正式题目与自动提取结果严格分层，日常练习页面只读取 `已核对/`。

## 目录说明

- `已核对/`：经人工确认后可以练习的题目。当前包含一份选择题、一份案例分析题和一份论文训练题，均为本知识库自编内容。
- `待核对/`：从本机登记 PDF 或合规公开页面提取的批次。即使已识别到题目，也必须人工核对题干、选项、答案、解析、来源和知识点后才能提升。
- `来源索引/`：只保存来源名称、公开 URL、访问状态和备注。遇到登录、会员、验证码或其他访问控制时，只登记索引，不保存受限题目正文、答案或解析。
- `题库模型.py`：正式题目的加载、校验、筛选与安全查找模型；不访问 PDF、网页或私有路径台账。

## 正式题目要求

每题均使用稳定 ID（`source-id:question-no`），状态必须为 `verified`，并且只能关联现有知识点。来源只允许公开 HTTP(S) URL 或空 URL，不能写入本机绝对路径、Cookie、令牌或请求签名。

- 选择题：2 至 6 个不重复的 `A` 至 `F` 选项，正确答案必须在选项中。
- 案例分析：包含材料；每个分问必须有 ID、提示、分值和至少一个参考要点。
- 论文：包含题目、写作要求和至少一个参考提纲项。

解析与答案需要人工确认；缺失、疑似错位或仅规则提取的内容一律保留在 `待核对/`。第三方受限内容不复制进本目录。

## 使用方式

1. 导入一份本机登记 PDF 到待核对层：

   ```bash
   python3 系统架构师知识库/导入题库.py --source-id q002 --answer-source-id q003
   ```

   `q002` 是试卷的私有台账 ID，`q003` 是同年度答案解析 PDF 的私有台账 ID。再次提取同一批次需显式加 `--replace`。工具不会扫描目录、复制 PDF，也不会自动提升任何候选题。

2. 打开 `题库数据/待核对/q002.json`，逐题回看本机 PDF，核对题干、选项、题号、答案、解析和知识点。候选答案只用于辅助核对，不能直接信任。

3. 将确认后的题目按正式模型手工追加到 `已核对/选择题.json`、`案例分析.json` 或 `论文.json`。必须填写 `verified` 状态、来源、关联知识点、参考答案/要点和核对说明。

4. 启动本地服务后访问 `http://127.0.0.1:8017/#practice`。选择题提交后判分；案例和论文保存自评后可展开参考要点，并可将复盘追加到现有 Markdown 学习档案。

软考达人目前登记在 `来源索引/外部来源.json`。其受限题目只保留公开入口和访问状态，不抓取正文、答案、解析、Cookie、令牌或请求签名。
