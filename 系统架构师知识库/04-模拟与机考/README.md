# 模拟与机考

## 模拟节奏

- 9 月中旬前：每周完成一套综合或两道案例的限时训练。
- 9 月中旬后：至少 3 次三科联动模拟；每次都要有计时、复盘和下周调整。
- 10 月最后两周：以错题二刷、论文提纲、机考输入和答题节奏为主，不再大量扩充新资料。

| 类别 | 外部项目位置 | 用途 |

| 综合/案例模拟卷 | `07、模拟题/` | 查漏和限时训练；不等同于真题 |
