# 学习计划与模板

本目录是知识库的**流程骨架**：把「读知识点 → 做题 → 复盘 → 调整」固定成可执行的节奏。
所有文件均为本知识库原创模板，不含第三方教材或试题正文。

| 文件 | 用途 | 何时用 |
|---|---|---|
| [12 周学习总计划](01-学习总计划.md) | 从当前日期到 10 月考试的周节奏 | 开始前读一次，每周日对照 |
| [错题本模板](03-错题本模板.md) | 记录错误原因与下次判断规则 | 每次做完综合知识 |

| [论文素材库模板](05-论文项目素材库模板.md) | 沉淀真实项目素材与三篇提纲 | 每周五、周日 |
| [总体知识思维导图](07-总体知识思维导图.md) | 三科知识全景与相互引用 | 建立框架时看 |

## 使用顺序

1. **先建立框架**：读一遍 [学习总计划](01-学习总计划.md) 与 [总体知识思维导图](07-总体知识思维导图.md)。
2. **日常循环**：读知识点 → 限时做题 → 用对应模板记录 → 周日复盘。
3. **复盘只调两项**：每周只把两个最高频弱项排进下周，避免全面铺开。

## 与知识点库的配合

知识点阅读器提供 **20 章、503 个知识点**，每个知识点包含：

- 核心结论、结构化理解（定义/关注点、机制/组成、场景/限制）
- 考试使用（综合知识 / 案例分析 / 论文三科视角）
- 考纲要求（434 个知识点已对齐考试大纲条目）
- 可展开的教材文字层

学习时建议：**先读知识点建立概念 → 立刻做对应真题 → 用错题本记录**。
只读不练、或只刷题不回看知识点，都是常见的低效模式。

## 考试事实

- 三科：综合知识（75 题 / 150 分钟）、案例分析（5 选 3 / 90 分钟）、论文（4 选 1 / 120 分钟）。
- 合格线：三科同一次考试均 **≥ 45 分**，成绩不跨期保留。
- 形式：机考。
- 2026 年下半年开考窗口：**10 月 24 日至 27 日**；个人场次以准考证为准。
