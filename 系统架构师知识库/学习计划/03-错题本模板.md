# 错题本模板

记录的目的不是「收藏错题」，而是**提炼出下次判断的规则**。
一条没有「下次判断规则」的错题记录，等于没记。

## 单题记录

```markdown
### YYYY-MM-DD｜<科目>｜<知识点编号> <知识点标题>

- **题干要点**：（用自己的话压缩成一句，不要抄原题）
- **我的答案**：X　**正确答案**：Y
- **错误类型**：概念不清 / 审题偏差 / 记忆混淆 / 计算失误 / 时间不足
- **为什么错**：（写真实原因，不要写“没记住”）
- **下次判断规则**：（写成可执行的判断句，例如“看到‘保证不泄露’就直接定位到保密性，不要选完整性”）
- **复习安排**：+3 天 ☐　+10 天 ☐　+28 天 ☐
```

### 错误类型参考

| 类型 | 典型表现 | 对策 |
|---|---|---|
| 概念不清 | 两个相近概念选错 | 回知识点页读定义，做对比卡 |
| 审题偏差 | 问“不正确”的选了正确的 | 圈出题干问法再作答 |
| 记忆混淆 | 数字/名称记串 | 编口诀或放进对比表 |
| 计算失误 | 会但算错 | 固定草稿格式，留验算时间 |
| 时间不足 | 没做完 | 练单题限时 |

## 二刷触发条件

满足任一条件即安排二刷：

- 同一知识点错 2 次以上；
- 同一错误类型连续出现 3 次；
- 距上次做对已超过 28 天且该题曾错过。

> 不要把所有错题同时重做——每周只挑两个专题。
