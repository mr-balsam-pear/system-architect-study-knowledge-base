# 使用说明与官方来源

## 这个知识库是什么

一个**本地优先**的系统架构设计师备考框架。它提供知识点阅读、真题索引、
互动练习、章节播客和学习档案，但**不包含**受版权保护的教材、试题正文或答案解析。

## 数据分层

| 层级 | 内容 | 位置 | 是否公开 |
|---|---|---|---|
| 知识点 | 503 个教材知识点（20 章） | `site/knowledge-data.js` | 公开 |
| 学习框架 | 计划、模板、思维导图 | `学习计划/` | 公开 |
| 互动题库 | 已人工核对的题目 | `题库数据/已核对/` | 公开 |
| 来源索引 | 仓库名、URL、许可、访问状态 | `题库数据/来源索引/外部来源.json` | 公开 |
| 真题索引 | 年份、科目、标题（无路径） | `site/data.js` | 公开 |
| 私有台账 | 本机绝对路径白名单 | `真题台账私有.json` | 本机 |
| 待核对层 | 机器提取的候选题 | `题库数据/待核对/` | 本机 |
| 第三方资料 | 仓库快照、PDF、音频 | `2026下半年系统架构师备考资料/` | 本机 |

**公开仓库只保留「代码 + 自编题 + 不含正文的来源索引 + 知识点派生数据」。**

### 2026 年考试安排

- **下半年开考窗口**：10 月 24 日至 27 日
- **三科**：综合知识（75 题 / 150 分钟）、案例分析（5 选 3 / 90 分钟）、论文（4 选 1 / 120 分钟）
- **合格线**：三科同一次考试均 ≥ 45 分，成绩不跨期保留
- **形式**：机考

> 个人考试日期、场次与考点以**准考证**为准。

## 使用边界

1. 本知识库与考试主管机构、出版社、原作者**无隶属或授权关系**。
2. 知识点中的教材文字层来自公开清洗稿，可能有 OCR 错误；
   **图表、公式与版式请回源教材核对**。
3. 第三方题库的答案与解析在人工核对前**不可信任**。
   本仓库的 `已核对/` 只接受经过人工确认的题目。
4. 请自行确认所持资料的使用权限，不要上传受版权保护的正文。

## 快速开始

```bash
python3 系统架构师知识库/本地学习服务.py
```

打开 <http://127.0.0.1:8017/>，或在任何 Markdown 阅读器中直接浏览 `学习计划/`。
