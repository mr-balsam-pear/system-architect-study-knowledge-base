# 冲刺指挥台视觉原型正式集成设计

## 背景

2026-08-12 会话中已确认将知识库从“统计卡片墙”调整为“学习工作台”，随后又确认采用更生动的深色“冲刺指挥台”原型。现有正式站点已经完成主题切换、互动题库、知识点阅读、真题预览、学习档案和章节播客等功能，但首页结构与视觉层仍主要沿用早期浅色纵向页面，未完整继承已确认原型。

本轮只重构正式站点的布局、视觉层级和必要的页内导航行为，不重写既有业务逻辑，不改变数据接口，不删除生产文件。

## 目标

1. 正式首页采用“先行动、后统计”的冲刺工作台结构。
2. 黑夜主题呈现深靛色指挥台、琥珀色行动信号和克制的紫色辅助层；白天主题保持同一结构并提供高对比浅色映射。
3. 章节播客保持冲刺指挥台二级入口，不加入一级导航。
4. 现有题库、知识树、真题、训练中心、学习档案、主题持久化和播客播放能力全部保留。
5. 320、375、414、768 像素宽度下无横向滚动、无按钮文字折成两行、无固定播放器遮挡正文或提交按钮。

## 设计系统

### Hallmark 结构

- Genre：`atmospheric`，用于体现考试临近、夜间专注和持续推进感。
- Macrostructure：`Workbench`，页面首先展示当前动作和真实工具，而不是营销式 Hero 或均匀卡片阵列。
- Enrichment：无图片；使用纯 CSS 的阶段轨迹、状态信号和轻量背景光域。
- 动效：仅使用透明度与位移，最多包含面板进入、按钮按压和迷你播放器出现三类；遵循 `prefers-reduced-motion`。
- 标题保持正体，不使用斜体标题或渐变文字。

### 色彩与令牌

所有颜色、字体、间距、圆角、时长和缓动均通过命名 CSS 变量引用。新增 `site/tokens.css` 作为设计令牌源，`styles.css` 不直接临时声明十六进制、RGB 或 OKLCH 色值。

黑夜主题：

- 深靛色画布与略亮的工具面板；
- 琥珀色只用于主要行动、进度和紧急信号；
- 紫色只用于辅助状态与章节编号；
- 青色只用于知识点、成功或信息状态，控制在少量面积内；
- 正文使用偏暖浅灰，次要文字满足可读对比度。

白天主题：

- 暖白画布与冷白工具面板；
- 保留琥珀主行动、紫色辅助状态和青色知识语义；
- 不改变内容结构、控件尺寸和信息优先级。

字体只使用本机可用字体栈，避免外部网络依赖。显示字体、正文和等宽状态文字分别绑定到 `--font-display`、`--font-body` 和 `--font-mono`。

## 页面结构

### 顶部指挥栏

顶部从大面积渐变 Hero 调整为紧凑指挥栏：

- 左侧显示 `SA` 标识、“系统架构师 · 冲刺指挥台”和 `2026 H2 / LOCAL STUDY OS`；
- 右侧显示考试窗口、动态倒计时和白天/黑夜主题切换；
- 下方保留一级导航：学习闭环、直接学习、互动题库、真题索引、训练中心；
- 一级导航不增加“章节播客”。

### 今日指挥台

首屏内容按 7:5 左右比例组织：

- 左侧为“今日任务序列”，突出三步闭环：清理到期复习、完成限时训练、留下判断规则；
- 任务按钮链接到现有学习闭环、题库和记录能力，不制造新的数据来源；
- 右侧为播客二级入口，显示真实的 18 期与第 2–20 章覆盖信息；
- 原有“每周执行路径”中的案例、论文和错题入口合并到任务序列及后续训练中心，不重复形成四张同权卡片。

### 学习闭环仪表盘

仪表盘继续使用现有 API 数据，但改变视觉层级：

- “今日复习”是主面板，占据更大区域；
- “近 7 天记录”“薄弱专题”“论文素材”作为次级状态列；
- 空状态保持诚实，不虚构正确率、分数或完成量；
- 所有原有 ID 保持不变，避免破坏 `app.js` 数据绑定。

### 章节播客二级工作区

入口点击后仍在同一页面展开节目库：

- 工作区标题、返回按钮和说明形成独立工作区头部；
- 左侧为 20 章节目单，使用章节编号、标题、时长与本机进度；
- 右侧为当前节目主面板，保留原生 `audio controls`、播放按钮、进入知识点和主动记录；
- 第 1、4 章显示弱提示并隐藏失效播放控件；
- 固定迷你播放器使用紧凑三列结构，移动端改为两行，不遮挡页面底部内容。

### 题库、知识点、真题与训练区

这些区域保留现有 DOM ID、表单、筛选器和数据行为，但统一改成工作台组件语言：

- 区域标题不再使用重复的大卡片容器；
- 筛选器成为工具条，阅读器成为主工作面板；
- 题库列表和知识树维持左侧工具栏、右侧工作区的桌面结构；
- 小屏切为单列，列表位于阅读器之前；
- 真题记录从均匀卡片改为紧凑索引行，仍可打开受控 PDF 和知识点关联；
- 训练中心保留案例、论文、模拟和资料入口，但降低其相对权重。

## 交互与状态

- 主题切换保持当前 `localStorage` 键、系统偏好回退、首屏无闪烁和准确 ARIA 名称。
- 所有按钮和链接至少 44 像素触控高度，并具备默认、hover、focus-visible、active、disabled 状态；有异步状态的现有控件继续显示加载、错误和成功反馈。
- 点击指挥台任务只导航或打开现有能力，不自动写入学习档案。
- 播客播放、暂停、切换和刷新恢复沿用现有状态机；只有显式记录才打开学习表单。
- 页面不新增外部字体、图片或运行时依赖。

## 响应式与可访问性

- `html` 与 `body` 使用 `overflow-x: clip`，不得通过 `hidden` 掩盖布局错误。
- 在 768 像素以下，指挥台、播客、题库、知识阅读器和真题预览均改为单列。
- 在 320、375、414 像素宽度下，一级导航允许受控横向滚动或合理换行，但单个可点击标签不得折成两行。
- 标题使用 `overflow-wrap: anywhere` 和 `min-width: 0`，避免长中文或英文术语撑破容器。
- 焦点环始终可见，颜色对比不低于 3:1；正文和控件文字满足 WCAG AA。
- `prefers-reduced-motion` 下移除空间位移，仅保留不超过 150ms 的透明度变化。

## 验收标准

1. 首屏呈现紧凑指挥栏、今日任务序列和播客二级入口，不再是旧版大渐变 Hero 加四张同权任务卡。
2. 白天和黑夜主题结构一致，主题按钮、持久化、系统偏好和首屏渲染继续正常。
3. 学习档案、题库、知识点、真题、训练中心和播客所有既有功能可用，原有自动化测试全部通过。
4. 播客节目库显示 20 章、18 期；第 1、4 章无失效控件；第 7 章可联动知识点；固定播放器不遮挡内容。
5. 题库可完成筛选、单题、整卷、答题卡、交卷汇总和只读复盘。
6. 320、375、414、768 以及桌面宽度浏览器验收均无横向滚动、文字截断、按钮双行或固定控件遮挡。
7. 页面无控制台错误；Python、JavaScript 状态测试、语法检查、XMind 校验和 `git diff --check` 全部通过。
8. Hallmark 58 项反模板检查全部通过；CSS 顶部包含本次 Workbench 结构印记。

## 非目标

- 不实现新的成绩预测、虚构正确率或考试通过概率；
- 不扩充题库内容；
- 不更换服务端框架；
- 不复制或提交本机 WAV/PDF；
- 不加入外部图标库、动画库或 Web Font；
- 不把播客提升为一级导航。
