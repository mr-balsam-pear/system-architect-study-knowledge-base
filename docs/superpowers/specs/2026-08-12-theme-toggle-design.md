# 白天 / 黑夜主题切换设计

## 目标

为“系统架构师知识库”页面增加一个易发现、可访问且可持久化的主题切换按钮，使用户能在浅色（白天）和深色（黑夜）面板样式之间切换。

## 界面与交互

- 按钮位于顶部横幅的右上角，与站点标题区分开，且不影响导航链接的换行布局。
- 浅色主题下按钮显示 `☀️ 白天`；深色主题下显示 `🌙 黑夜`。按钮的可访问名称说明点击后将切换到另一主题。
- 初次访问时，如没有已保存的偏好，则跟随操作系统的颜色偏好：系统浅色对应白天，系统深色对应黑夜。
- 用户点击按钮后，页面立即更新主题，并将选择保存在浏览器 `localStorage`。后续打开页面优先采用该选择，不再跟随系统变化。
- 若本地存储不可用或数据异常，页面仍按系统偏好（或白天）正常显示和切换。

## 样式范围

通过挂在根元素上的主题数据属性和 CSS 自定义变量实现深色样式，避免为每个组件写独立的主题判断逻辑。黑夜主题将覆盖：

- 页面画布、正文文字、弱化文字和分隔线；
- 内容区、卡片、阅读器、题库列表及筛选区；
- 输入控件、下拉框、文本域、折叠内容；
- 真题与学习记录弹窗及其遮罩；
- 交互状态（悬停、选中、禁用、焦点）和已有的正确/错误反馈。

品牌青绿色和橙色强调色保留语义，但根据深色背景调整明度，确保文字与背景仍有足够对比度。

## 可访问性

- 主题按钮使用原生 `button` 元素，提供 `aria-pressed` 以反映黑夜模式是否开启，并为状态变化设置准确的 `aria-label`。
- 按钮保留清晰的键盘焦点样式；表情符号只承担视觉提示，文字保留为操作主信息。
- 主题切换不改变阅读位置、不重载页面，也不影响既有对话框或练习状态。

## 验收标准

1. 点击按钮可在白天和黑夜主题间来回切换，按钮文字、图标及 ARIA 状态同步更新。
2. 深色主题的正文、内容面板、侧栏、筛选控件、弹窗和交互状态均无突兀的浅色背景或不可读文本。
3. 刷新页面后保留手动选择；未设置选择时按系统偏好决定初始主题。
4. 窄屏下按钮不会遮挡标题或导航，键盘可聚焦并触发。
