# 系统架构师知识库编辑式工作区排版优化设计

## 背景

当前知识库已经完成 Hash SPA、多工作区、昼夜主题、共享弹窗和跨路由播客播放器。功能路径完整，但部分页面仍有面板等权、卡片堆叠、正文区域受挤压、窄屏密度过高等问题。本轮只优化布局与排版，不改变路由、数据模型、学习记录格式和业务能力。

## 已确认方向

- 优化幅度：明显重排。
- 信息密度：中等密度，兼顾阅读舒适度与学习效率。
- 桌面知识目录：窄侧栏常驻，可一键收起。
- 视觉系统：保留深墨背景、琥珀行动信号、紫色辅助层以及昼夜主题。
- 交互边界：保留现有路由、状态恢复、共享学习记录弹窗和跨路由播客播放器。

## 设计目标

1. 消除横向溢出、遮挡、错位、控件换行和弹窗内容不可达等格式错误。
2. 以非对称编辑式编排替代等权面板墙，让主要学习内容获得清晰的第一视觉层级。
3. 建立统一的标题、正文、摘要、元数据、表单与操作区排版节奏。
4. 在桌面维持高效多栏工作流，在 768px 以下转为完整单列阅读流。
5. 保持已有状态快照，使收起目录、筛选、活动实体和阅读位置在路由切换后可恢复。

## 全局布局

### 应用壳

- 桌面端保留左侧主导航，但压缩非必要装饰和状态区域，主内容采用更宽、偏左的编辑式画布。
- 工作区标题不再统一使用同一种大 Hero。工具型页面使用紧凑页头，首页与训练中心保留更强的展示标题。
- 主内容采用三档语义宽度：阅读正文、操作工作区、全宽索引。页面按内容性质选择，而非统一套用最大宽度。
- 所有页面底部预留大于迷你播放器实际高度的安全空间。

### 响应式

- `> 1024px`：桌面非对称多栏。
- `769–1024px`：压缩侧栏与辅助区，避免正文行宽过窄。
- `<= 768px`：隐藏桌面主导航，使用工作区抽屉；所有内容进入单列。
- `<= 480px`：弹窗变为底部面板，操作按钮按重要性纵向排列。
- 必须在 320、375、414、768、1280px 下无横向滚动、无文字遮挡、无双行主操作文本。

## 工作区设计

### 今日指挥台

- 首页只保留一个主行动区，作为下一步学习入口。
- 最近学习和最近播客成为次级连续入口，不再与主行动等权。
- 到期复习、薄弱专题、论文素材使用紧凑摘要带，不渲染完整列表。
- 减少卡片边框数量，以分隔线、背景层次和留白建立节奏。

### 知识点阅读器

- 桌面布局为“可收起窄目录 + 主正文”。目录默认常驻，收起状态写入 `WorkspaceState`。
- 目录只突出当前章节和活动知识点，其余内容降低视觉权重。
- 正文行长控制在约 60–70 个中文字符的视觉宽度，正文区域居于主画布而非填满全部可用宽度。
- 核心结论为醒目的首段块；结构化理解采用非等宽区域或纵向条目；考试使用采用紧凑分区。
- 教材文字层默认折叠，展开后仍保持正文行长和段落节奏。
- 窄屏目录通过抽屉进入，不占据正文上方的大段垂直空间。

### 互动题库

- 桌面采用“题目索引窄栏 + 主答题区”，主答题区权重明显更高。
- 筛选器在桌面为单行工具条，移动端收进筛选抽屉。
- 整卷模式隐藏索引栏但保留状态；单题模式保留上一题、下一题和答题进度。
- 选项、案例文本框和论文输入区统一高度、边界、焦点和错误状态。

### 本机真题与详情

- 索引页使用高密度纵向列表或不等宽条目，不再采用等宽双列卡片墙。
- 详情页以 PDF 为主视图，关联知识点为可收起辅助栏。
- PDF 不可用时，元数据、返回索引、关联知识点与记录入口仍保持可见。
- 移动端 PDF 与关联区纵向排列，关联区不得挤压或覆盖预览。

### 章节播客

- 桌面采用窄节目索引和宽播放器区域，当前节目标题与进度成为主要视觉。
- 不可播放章节保持可理解但降低权重，不显示误导性的播放操作。
- 迷你播放器保持跨路由，窄屏仅保留标题、进度与播放按钮。

### 学习档案

- 到期复习为主区，近期记录、薄弱专题和论文素材为不同尺寸的次级区域。
- 列表使用清晰的日期、结果、知识点层级，不使用重复卡片边框。
- 空状态必须提供明确下一步，不扩大为无意义的大空白面板。

### 训练中心

- 案例分析作为当前主路径，占据最大区域。
- 论文写作与模拟训练作为次级路径，资料台账保持安静文本入口。
- 页面强调训练顺序与行动，不重复展示首页摘要信息。

## 弹窗与覆盖层

- 桌面学习记录弹窗限制为舒适表单宽度，字段按任务顺序编排。
- 移动端采用底部面板，标题与关闭按钮固定在可见区域，内容独立滚动。
- 表单错误、加载、成功和禁用状态必须稳定占位，不能造成布局跳动。
- 导航、目录、筛选和辅助栏抽屉共用遮罩、焦点恢复和背景滚动锁定规则。

## 状态与行为

- 知识工作区新增 `sidebarCollapsed` 快照字段。
- 题库筛选抽屉和真题辅助栏只保存必要的展示状态，不改变 API 请求参数。
- 目录收起、筛选、活动知识点、活动题目和滚动位置在路由切换后恢复。
- 任何排版修改不得重建 `<audio>` 元素或中断播客进度。

## 可访问性与视觉约束

- 所有可收起区域按钮必须同步 `aria-expanded` 和 `aria-controls`。
- 移动抽屉必须有可访问名称、Esc 关闭、焦点进入和焦点返回。
- 标题使用 upright 字体；不使用渐变文字、装饰性图标墙、厚侧边色条或嵌套卡片。
- 颜色只来自 `tokens.css`；组件样式不得写入原始颜色值。
- `prefers-reduced-motion` 下只保留短时透明度变化。

## 验收标准

- 所有现有 Python、Node 契约与语法检查通过。
- `#/today`、`#/knowledge`、`#/practice`、`#/questions`、一个真实真题详情、`#/training`、`#/podcasts`、`#/records` 均能正常使用。
- 320、375、414、768、1280px 下无横向滚动、遮挡、溢出或双行主操作文本。
- 知识正文视觉行长稳定，目录收起/恢复正确。
- PDF 辅助栏、题库索引栏和筛选抽屉在不同宽度下切换正确。
- 迷你播放器不遮挡页面最后一个操作元素。
- 昼夜主题、浏览器前进后退、工作区状态和播客跨路由播放无回归。
- Hallmark 58 项审计全部通过。

## 非目标

- 不新增学习功能、API 或数据文件。
- 不修改 Markdown 学习档案格式。
- 不更改 Hash 路由命名。
- 不更换主题色和品牌名称。
- 不引入前端框架或第三方组件库。
