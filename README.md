# 系统架构设计师学习知识库

一个本地优先的系统架构设计师备考框架，提供：

- **503 个教材知识点**阅读器（20 章、含正文分段、三科考试视角与全文搜索）与本地学习仪表盘；
- 单选题、案例分析和论文的互动练习；
- Markdown 周报与专题复盘档案；
- 冲刺指挥台中的章节播客：本机续播、节目库与知识点就近播放；
- 从用户本机、已授权 PDF 生成“待核对”题库批次的工具；
- 对第三方题库只保存公开来源索引，不绕过登录、会员、验证码或请求签名。

## 快速开始

要求：Python 3.10+；如需从本机 PDF 导入，安装 `pypdf`。

```bash
python3 系统架构师知识库/本地学习服务.py
```

打开 <http://127.0.0.1:8017/>，可在冲刺指挥台的“章节播客”二级入口收听本机节目，也可在对应知识点页就近播放。进度只保存在浏览器本机；只有主动点击“记录本章收听 / 复盘”并提交，才会追加到本机 `系统架构师知识库/学习档案/`。第 1、4 章当前暂无节目。

运行测试：

```bash
python3 -m unittest 系统架构师知识库/tests/test_题库.py -v
python3 -m unittest 系统架构师知识库/tests/test_本地学习服务.py -v
```

## 数据与版权边界

本公开仓库只包含代码、自编训练题、知识点派生数据和不含正文的来源索引。教材 PDF、真题 PDF、音频、个人学习记录、本机绝对路径台账、教材源稿、第三方仓库快照及 PDF 提取全文都由 `.gitignore` 排除。

### 从 GitHub 摄取材料（全部本机）

`2026下半年系统架构师备考资料/github提取/` 用于存放从公开 GitHub 仓库拉取的资料快照（约 599 MB、12 个仓库）。该目录整体被忽略，**不会进入公开仓库**。

```bash
cd "2026下半年系统架构师备考资料/github提取/_工具"

# 1. 拉取公开仓库固定 commit 快照，并写入 _来源清单/
python3 拉取仓库.py --repo xiaomabenten/system_architect --repo wujiaming88/awesome-ruankao

# 2. 清点内容，生成本机台账与可公开的来源索引条目
python3 清点来源.py --write

# 3. 从教材清洗稿生成知识库源稿，再生成 503 个知识点页
python3 生成教材源稿.py --textbook "<教材清洗稿目录>" --outline "<大纲文件>" --repo <owner/name> --commit <sha>
python3 "系统架构师知识库/生成知识点页面.py"

# 4. 登记本机真题 PDF 为私有白名单台账
python3 生成私有台账.py --write
```

### 把真题导入互动练习

私有台账建立后，可用它把某份试卷提取为“待核对”批次：

```bash
python3 系统架构师知识库/导入题库.py --source-id q002 --answer-source-id q003
```

导入内容只会写入 `题库数据/待核对/`；请人工核对题干、选项、答案、解析与来源后，才可提升到 `已核对/`。第三方题目（含自动提取的“真题”）的答案与解析在核对前不可信任，不要上传受版权保护的题目正文、答案解析或教材。

详细约束见 [题库说明](系统架构师知识库/题库数据/README.md) 与 [真题索引说明](系统架构师知识库/02-真题索引/README.md)。
